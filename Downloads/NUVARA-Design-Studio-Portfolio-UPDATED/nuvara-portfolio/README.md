# NUVARA — Portfolio Website

A responsive multi-page portfolio starter for **NUVARA Design Studio**, inspired by the editorial, minimal and warm-neutral visual direction of the reference image supplied in the conversation.

## Structure

- `index.html` — home / portfolio
- `about.html` — studio presentation
- `contact.html` — contact page
- `project-nuvara.html` — project page
- `project-modular.html` — project page
- `project-residential.html` — project page
- `project-identity.html` — project page
- `assets/css/style.css` — complete styling
- `assets/js/script.js` — menu + contact form interaction
- `assets/images/` — put your real project images and logo here

## Run locally

### VS Code + Live Server
Open the folder in VS Code, right-click `index.html`, then choose **Open with Live Server**.

### Terminal
From the project folder:

```bash
start index.html
```

For a local development server, use Live Server or another static server.

## Replace the placeholders

1. Replace the `N` inside `.brand-mark` with the real NUVARA logo once available.
2. Add your project images to `assets/images/`.
3. Replace the CSS placeholder image classes with real image URLs/paths.
4. Replace the example Instagram link.
5. Replace `hello@nuvara.studio` with the real email.
6. Replace project texts with your real portfolio content.

## Visual direction

The layout uses:
- warm beige / stone background
- editorial serif typography
- clean sans-serif navigation
- large project imagery
- generous margins
- thin borders
- numbered projects
- minimal animations
- responsive mobile layout

It is intentionally designed as a **design-studio portfolio**, not a generic template.
